\section{Asymmetric intersection number and non-examples}
\label{sec:asymmetric}

Up to Proposition~\ref{prop:recoverintersection}, we managed to construct a geodesic current associated to a curve functional $f$ that wasn't necessarily symmetric.
One can hope that this asymmetric intersection number can be realized as some version of an asymmetric intersection number with that oriented geodesic current. Section~\ref{sec:asymmetric} shows examples manifesting this is not the case: there are asymmetric curve functionals that are not realized as asymmetric intersection numbers with oriented geodesic currents.

The asymmetric intersection number is an intersection number between oriented curves, defined analogously as the geometric intersection number but only considering right-handed intersections, as in Definition~\ref{def:righthandedcrossing}.

\begin{definition} Given two oriented curves $C,D$, the asymmetric intersection number is the minimal number of right handed crossings in within the homotopy class representatives of $C$ and $D$.
\end{definition}

Develop these curves in the universal cover of the triangular punctured torus, and consider the same triangulation as in Figure~\ref{fig:shortcurves} lifted to the universal cover.
The corresponding lifts of geodesics intersect the edges of the triangulations, which we orient. If we note the asymmetric intersection number of these geodesics as we develop the torus further and further, which corresponds to taking more powers of the curve, and keep track of the oriented intersections, we obtain the following diagrams of asymmetric intersections for each curve (color coded).
