\subsection{A new expression for the Thurston metric}


In \cite[Theorem~8.5]{Thu98:MinimalStretch} Bill Thurston defines the following (asymmetric) metric on $\Teich(S)$.

\[
d_{\mathit{Thu}}(\Sigma,\Sigma') \coloneqq \sup_{\lambda \in \ML}\log \frac{L(\lambda;\Sigma)}{L(\lambda;\Sigma')}
\]

As an immediate application of Theorem \ref{thm:intersect} we give a new characterization of Thurston metric in terms of a supremum over functionals on curves.

\begin{corollary}


\[
d_{\mathit{Thu}}(X,Y)=\sup_{f} \frac{f(X)}{f(Y)}
\]

where $f$ runs over all non-zero functionals $f : \mathcal{C}(S) \to \mathbb{R}$ satisfying convex union, additive, stability and homogeneity properties.
\end{corollary}
\begin{proof}
\[
d_{\mathit{Thu}}(X,Y)=\sup_{f} \frac{f(X)}{f(Y)} = \sup_{\mu \in \mathcal{G}\mathcal{C}(S)} \frac{i(\mu,X)}{i(\mu,Y)} = \sup_{\lambda \in \ML(S)} \frac{i(\lambda,X)}{i(\lambda,Y)}
\]
The first equality follows by our Theorem~\ref{thm:intersect}, and the second equality follows because, by \cite[Theorem~8.5]{Thu98:MinimalStretch}, the distance is attained by a minimal stretch map, which dilates the hyperbolic lengths by the same bounded amount.
\end{proof}

Let

\begin{definition}
  A cross-ratio is a continuous function $B\colon \Gamma^{[4]} \to \mathbb{R}$ invariant under the diagonal action of $\pi_1(S)$ and satisfying:
  \begin{itemize}
      \item (symmetry) $B(x,y,z,w)=B(z,w,x,y)$
      \item (additivity) $B(x,y,z,w) + B(x,y,w,u)=B(x,y,z,u)$ for all $x,y,z,w,u \in \partial \Gamma$ such that $(x,y,z,w), (x,y,z,u) \in  \Gamma^{[4]}$
  \end{itemize}
\end{definition}
We say that $B$ is \emph{positive} if for all $x,y,z,w$ in this cyclic order, we have $B(x,y,z,w) \geq 0$. \\
Recall that if $c=[\gamma]$ we can define the length 
\[
  l_{\rho}^{\alpha}(c)=B_{\rho}^{\alpha}(\gamma^+,\gamma^-,z,\gamma(z)).
 \]

The properties of cross ratio ensure this is well-defined.
In \cite{MZ18:PositiveReps} it is shown that if $B_{\rho}^{\alpha}$ is positive, then there exists a unique
geodesic current $\mu_{\rho}^{\alpha}$ so that $l_{\rho}^{\alpha}(c)=i(\mu_{\rho}^{\alpha},c)$. In particular, $l_{\rho}^{\alpha}$ extends to geodesic currents as an intersection number.
We can give another characterization of positivity for cross-ratio in terms of the length function $l_{\rho}^{\alpha}$.
 
\begin{proposition}
 $B_{\rho}^{\alpha}$ is positive if and only if $l_{\rho}^{\alpha}$ satisfies smoothing condition.
\end{proposition}
\begin{proof}
From the above mentioned result in \cite{MZ18:PositiveReps}, the smoothing property follows. \\
On the other hand, if $l_{\rho}^{\alpha}$ satisfies smoothing, since additive union is also clear for $l_{\rho}^{\alpha}$, then we just apply theorem \ref{thm:intersect}
to obtain a geodesic current $\mu_{\rho}^{\alpha}$. Finally, we define the cross-ratio 
\[ 
B_{\rho}^{\alpha}(a,b,c,d)\coloneqq \mu_{\rho}^{\alpha}([a,b)\times[c,d)).
\]

It obviously satisfies the properties of cross-ratio in \cite{MZ18:PositiveReps} because of the definition of geodesic current, and it's positive.

\end{proof}

Further, we can study convexity of functions along paths in Teichm\"uller space. This is important because it yields proofs of the \emph{Nielsen realization problem}, this is, every finite subgroup of the mapping class group of $S$ can be realized as a group of isometries on some hyperbolic metric.

A path $(\mu_t)_{t \in \mathbb{R}}$ in $\mathcal{G}\mathcal{C}(S)$ is called \emph{convex} if $\frac{1}{2}i(\mu_t + \mu_s)$ dominates $\mu_{\frac{s+t}{2}}$.
for all $s,t \in \mathbb{R}$.

For example, $\mu_t$ could be a path of Liouville currents in $\Teich(S)$.
If $\mu_t$ corresponds to a Teichm\"uller geodesic, then \cite[Example~22]{LR11:QuasiConvexityLengths} shows that $\mu_t$ is not convex.
On the other hand, if $\mu_t$ corresponds to an earthquake path \cite[Theorem~1]{Ker83:EarthquakeNielsenProblem}, to a WP-geodesic \cite[Corollary~4.7]{Wol87:WPNielsenProblem}, or paths related to certain shearing coordinates (of which Fenchel-Nielsen coordinates are an example)
\cite[Theorem~1.3]{BBFS13:ConvexityShearing}
All these yield, as corollaries, proofs of the Nielsen realization theorem.

We conjecture that

\begin{conjecture}
\label{thm:convexpath}
 Let $f \colon \mathbb{R}\mathcal{C}(S) \to \R$ be a function defined on weighted multi-curves satisfying
 
      \begin{enumerate}
     \item (convex union) Let $C_1$ and~$C_2$ be two curves
    on~$S$. Then
    \begin{equation*}\label{eq:additivity}
      f(C_1 \cup C_2) \leq f(C_1) + f(C_2).
    \end{equation*}
    \item (smoothing) For any essential crossing,
    \begin{equation*}\label{eq:smoothing}
      f\left(\mfig{curves-3}\right) \ge f\left(\mfig{curves-4}\right)
    \end{equation*}
    \item (stability and homogeneity)
   \begin{equation*} f(nC)=f(C^n)=nf(C) \end{equation*}
     \end{enumerate}
     
     For any convex path of currents $\mu_t$ the function $t \mapsto f(\mu_t)$ is convex.
\end{conjecture}

We observe that if this conjecture was true, it would imply that square root of extremal length is a convex function along convex paths but as a function of the curve, not as a function on Teichm\"uller space.
