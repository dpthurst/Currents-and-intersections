\section{Construction of the geodesic current}
\label{sec:construct}



\subsection{Countable additivity}
\label{sec:countable-additivity}

We prove countable additivity of the function $\mu_{f}$ by
proving approximation results. We first find controlled sequences of
decreasing nested RH boxes that we can show have measure going to zero.

\begin{definition}
Let the RH lift system $(p_1,p_2,q_1,q_2)$ determine a right-handed
box
$B = [s_1,s_2) \times [t_2,t_1)$, where $s_i = \ell_i^-$ and $t_i =
r_i^+$. Further assume that $\ora{r_2}$ is nested inside $\ora{r_1}$,
so the box is of type~2 or~3.

Define the \emph{vertical accordion} $F_{p_1,p_2,q_1,\vec{q_2}}$ of
boxes based at $B$ to be
the sequence of boxes, indexed by $k$, with $p_1, p_2, q_1$ constant
and $q_2$ successively translated by $r_1 = q_1 x Q_1$:
\[
  p_1^{(k)}\coloneqq p_1,\quad
  p_2^{(k)}\coloneqq p_2,\quad
  q_1^{(k)}\coloneqq q_1,\quad
  q_2^{(k)} \coloneqq q_1 x^k q_1^{-1}q_2.
\]
This defines boxes whose vertical height becomes narrower as $k$
grows, with the top endpoint fixed. See
Figure~\ref{fig:vertical-accordion}.

Similarly, if $\ora{\ell_1}$ is nested in $\ora{\ell_2}$, or
equivalently $\ora{p_1P_2}$ R-crosses $\ora{x}$, define the
\emph{horizontal accordion} $F_{\vec{p_1},p_2,q_1,q_2}$ by
\[
  p_1^{(k)}\coloneqq p_1 p_2^{-1}x^k p_2,\quad
  p_2^{(k)}\coloneqq p_2,\quad
  q_1^{(k)}\coloneqq q_1,\quad
  q_2^{(k)} \coloneqq q_1.
\]
\label{def:accordion}
\end{definition}

\begin{proposition}
  Let $F(k) = F_{p_1,p_2,q_1,\vec{q_2}}(k)$ or $F_{\vec{p_1},p_2,q_1,q_2}(k)$ be a
  vertical or horizontal accordion as above. Then
  \begin{itemize}
  \item each $F(k)$ is a RH box;
  \item $F(k+1) \subset F(k)$; and
  \item $\displaystyle \lim_{k \to \infty} \mu_f(F(k)) = 0$.
  \end{itemize}
\label{prop:finalfamily}
\end{proposition}

\begin{proof}
  We first prove the results in the case of vertical accordions,
  starting with checking that $F(k)$ is a box. Since $\ora{r_2}$ is
  nested inside $\ora{r_1}$, the NS dynamics of the group element $r_1
  = q_1 x q_1^{-1}$ translate $\ora{r_2}$ towards $r_1^+$, as depicted
  in Figure~\ref{fig:vertical-accordion}. In particular the cyclic
  order of the endpoints doesn't change, and we also automatically
  have $F(k+1) \subset F(k)$.

  To show the measures go to zero, we first reformulate the nesting
  condition algebraically. Note that
  $q_2Q_1 \cdot \ora{r_1} = \ora{r_2}$. Thus the $\ora{r_1}$ and
  $\ora{r_2}$ are nested iff $\ora{q_2Q_1}$ R-crosses $\ora{r_1}$. This is
  in turn equivalent to $Q_2 \cdot \ora{q_2Q_1} = \ora{Q_1q_2}$
  R-crossing $\ora{x}$; write $e = Q_1q_2$.

  In the RH orbit notation, we then have
  \begin{align*}
    a^{(k)} &= p_1 q_1 = a &
    b^{(k)} &= p_1 q_2^{(k)} = p_1 q_1 x^k q_1^{-1}q_2 = a x^k e\\
    c^{(k)} &= p_2 q_1 = c &
    d^{(k)} &= p_2 q_2^{(k)} = p_2 q_1 x^k q_1^{-1} q_2 = c x^k e.
  \end{align*}

We thus get the family of RH orbits given by
\[
\bigl([B]_{a,a x^k e,c,c x^k e}\bigr)_{k=0}^\infty.
\]
%Figure~\ref{fig:finalfamily} related the box to the orbit notation.
To show this family of orbits have measure going to zero,
by definition of $\mu_f$, we need to see that the nested limit
\[
\lim_{k \to \infty} \bigl(\mu_f([B]_{a,ax^ke,c,cx^ke})\bigr) = \lim_{k \to \infty} \lim_{n\to \infty} f([ax^ke x^n]) + f([cx^n])-f([ax^n])-f([cx^kex^n])
\]
goes to zero. By Lemma~\ref{lem:additivity-limit-2}, the double limit
exists, and by applying Proposition~\ref{prop:join-split-alg} we see
that it is equal to zero.

The case of the horizontal accordion is similar, but there are some
confusing inverses so we spell it out briefly.
Since $P_2 p_1 \cdot \ora{\ell_1} = \ora{\ell_2}$,
the assumption that $\ora{\ell_1}$
is nested inside $\ora{\ell_2}$ is equivalent to $\ora{P_2 p_1}$
R-crossing $\ell_2$, which in turn is equivalent to $\ora{p_1 P_2}$
R-crossing $\ora{x}$. In particular we have
\[
  \ora{\ell_1^{(k)}} = \bigl(p_1^{(k)}\bigr)^{-1} \cdot \ora{x}
  = \bigl(p_2^{-1} x p_2)^{-k} \cdot \ora{\ell_1}
  = \ell_2^{-k} \cdot \ora{\ell_1},
\]
which by NS dynamics of $\ell_2$ gives the picture on the left of
Figure~\ref{fig:horizontal-accordion}. In particular all of the $F(k)$
are boxes with $F(k+1) \subset F(k)$.

For the limiting computation, we set $e = p_1 P_2$, so that
\begin{align*}
  a^{(k)} &= p_1^{(k)} q_1 = e x^k c &
  b^{(k)} &= p_1^{(k)} q_2 = e x^k d\\
  c^{(k)} &= p_2 q_1 = c &
  d^{(k)} &= p_2 q_2 = d.
\end{align*}
Lemma~\ref{lem:additivity-limit-2} and
Proposition~\ref{prop:join-split-alg} apply as before.
\end{proof}

We now use Proposition~\ref{prop:finalfamily} to prove that $\mu_f$
is countably additive.
We will need to consider more types of boxes
than the half-open boxes we have been working with so far. For $B$ a
right-handed box $[s_1,s_2) \times [t_2,t_1)$, let
$\overline{B} \coloneqq [s_1,s_2] \times [t_2,t_1]$ and
$B^\circ \coloneqq (s_1,s_2) \times (t_2,t_1)$ be the corresponding
closed and open boxes.

\begin{lemma}\label{lem:extend1}
  For $B = [s_1,s_2) \times [t_2,t_1) \in \cB$ a right-handed box and
  any $\epsilon > 0$, there is a right-handed box $V(B,\epsilon) =
  [s_1',s_2) \times [t_2',t_1) \in \cB$ so that
  $s_1' < s_1$ and $t_2' < t_2$ and
  $\mu_f(V(B,\epsilon) \setminus B) < \epsilon$.
\end{lemma}

That is, $V(B,\epsilon)$ extends $B$ slightly down and to the left,
without increasing the mass much.

\begin{proof}
  Let $B = B_{p_1,p_2,q_1,q_2}$.
  By Proposition~\ref{prop:density}, there is some $q_3$ so that $q_3
  \cdot \ora{x}$ is nested inside $q_2 \cdot \ora{x}$; in particular
  $F_1 = F_{p_1,p_2,q_2,\vec{q_3}}$ is a vertical accordion, and for
  each $k$, $B \cup F_1(k)$ is a RH box. 
  By Proposition~\ref{prop:finalfamily}, there is $k_1$ large enough
  so thatx
  $\mu_f(F_1(k_1))<\epsilon/2$.
  Repeat the procedure to find a horizontal
  accordion $F_2$ abutting on $B \cup F_1(k_1)$. Again there is $k_2$
  large enough so that $\mu_f(F_2(k_2)) < \epsilon/2$, and set
  Let $V(B,\epsilon) \coloneqq B \cup F_1(k_1) \cup F_2(k_2)$.
\end{proof}

\begin{lemma}\label{lem:extend2}
  For $B = [s_1,s_2) \times [t_2,t_1) \in \cB$ a right-handed box and
  any $\epsilon > 0$, there is some $s_2',t_1'$ with
  $s_1 < s_2' < s_2$ and $t_2 < t_1' < t_1$ so that the region
  $W(B,\epsilon) = \bigl([s_1,s_2) \times [t_1',b_1)\bigr) \cup
  \bigl([s_2',s_2) \times [t_1,t_2)\bigr)$ is in $\mathcal{R}$ and satisfies
  $\mu_f(W(B,\epsilon)) < \epsilon$.
\end{lemma}

That is, $W(B,\epsilon)$ is a neighborhood of the upper and right
edges of~$B$ with small mass.

\begin{proof}
  Find $q_3$ so that $q_3 \cdot \ora{x}$ nested inside
  $q_1 \cdot \ora{x}$, so that $F_1 = F_{p_1,p_2,q_1,\vec{q_3}}$ is a
  vertical accordion. Similarly find $p_3$ so that $P_3 \cdot \ora{x}$
  is nested inside $P_2 \cdot \ora{x}$ and
  $F_2 = F_{\vec{p_3},p_2,q_1,q_2}$ is a horizontal accordion. Then
  for sufficiently large $k$, we have $\mu_f(F_1(k)) < \epsilon/2$ and
  $\mu_f(F_2(k)) < \epsilon/2$. Take
  $W(B,\epsilon) = (F_1(k) \cup F_2(k)) \cap B$.
\end{proof}
  
In the setting of Lemma~\ref{lem:extend2}, also set
\[
  W^\circ(B,\epsilon) \coloneqq \bigl([s_1,s_2] \times (t_1',t_1]\bigr) \cup
    \bigl((s_2',s_2] \times [t_1,t_2]\bigr);
\]
this is an open neighborhood of the upper and right edges of the
$\overline{B}$ in the subspace topology.

\begin{proposition}\label{prop:countablyadditive}
  The finitely additive measure $\mu_f$ is countably subadditive on $\cS$.
\end{proposition}

\begin{proof}
  Let $B_0$ be a right-handed box, and suppose we are given a
  countable covering of it: $B_0 \subset \bigcup_{i=1}^\infty B_i$. We
  must show that
  \[
    \mu_f(B_0) \le \sum_{i=1}^\infty \mu_f(B_i).
  \]
  Fix $\epsilon > 0$. For $i \ge 1$, set
  $V_i \coloneqq V(B_i, \epsilon/2^i)$. Also add one more set by setting
  $V_0 \coloneqq W(B_0,\epsilon)$ and $V_0^\circ \coloneqq W^\circ(B_0,\epsilon)$.

  Then $\{V_i^\circ\}_{i=0}^\infty$ cover $\overline{B_0}$, since
  the $B_i$ cover $B_0$, $B_i \subset V_i^\circ$, and
  $\overline{B_0}\setminus B_0 \subset V_0^\circ$. Since
  $\overline{B_0}$ is compact and the $V_i^\circ$ are open (in the
  subspace topology), we have a finite subcover; let $I \subset
  \mathbb{N}$ be the set of
  indices included in the subcover.

  By finite additivity, we then have
  \begin{align*}
    \mu_f(B_0) &\le \sum_{i \in I} \mu_f(V_i)\\
      &\le \sum_{i \in I, i \ne 0} \mu_f(B_i) + \sum_{i \in I, i \ne 0}
        \mu_f(V_i \setminus B_i) + \mu_f(V_0)\\
      &< \sum_{i=1}^\infty \mu_f(B_i) + 2\epsilon.
  \end{align*}
  Since $\epsilon$ was arbitrary, we are done.
\end{proof}

We now put everything together to obtain a geodesic current.

\begin{proposition}
Let $f \colon \mathcal{C}(S) \to \mathbb{R}$ be a functional on curves satisfying additivity, smoothing, stability and homogeneity.
Then $\mu_f$ is an oriented geodesic current.
\end{proposition}
\begin{proof}
By Propositions \ref{prop:limitexists}, \ref{prop:RHsemiring},
\ref{prop:finitely-additive} and~\ref{prop:countablyadditive}, $\mu_f$
is a finitely
additive and countably subbadditive pre-measure on $\mathcal{R}$. By covering by an exhaustion consisting of a union of boxes, we see $\mu_f$ is $\sigma$-finite.
Therefore, by Carathéodory extension Theorem~\ref{thm:caratheodory},
$\mu_f$ can be extend to a unique measure on
$\mathcal{A}_{\mathcal{R}}$, the $\sigma$-algebra generated
by~$\mathcal{R}$; we temporarily denote the extension $\hat\mu_f$.
Let $\cA$ be the Borel $\sigma$-algebra of $G(S)$.
Since $\cR \subset \cA$, we have $\cA_{\cR} \subset \cA$.

On the other hand, given a half-open box of geodesics
$B=[s_1,s_2) \times [t_2,t_1) \in \mathcal{B}$, it can be written as
an intersection of two countable unions of boxes in $\mathcal{R}$,
since, by Proposition~\ref{prop:density}, the set of elements in
$\mathcal{R}$ is dense in the subspace of half-open rectangles of
$G(S)$. It follows that $\cA \subset \cA_{\cR}$. (This is the same as
the standard argument one uses to prove
the Borel $\sigma$-algebra generated by half-rectangles with rational
endpoints is the usual Borel $\sigma$-algebra.)

Note that $\hat\mu_f$ is locally finite, since any compact subset of $G(S)$ can be covered by one of the boxes in $\mathcal{R}$, where the measure takes a finite value.
Therefore, $\hat\mu_f$ is a Borel and locally finite measure. 
By definition of $\mu_f$, the extension $\hat\mu_f$ is
$\pi_1(S)$-invariant. Finally, $\hat\mu_f$ is non-negative by
Proposition~\ref{prop:box-positive}.
\end{proof}

\subsection{
Recovering \texorpdfstring{$f$}{f} on curves}
\label{sec:recovery}

It remains to show that $\mu_f$ recovers $f$ as an intersection number on curves.

If $y$ is a hyperbolic element representing a closed curve
$C$ in the surface $S$, choose
$z \in \partial_{\infty} S \setminus \{ y_-, y_+\}$ so that
$y_-,\, z,\, y \cdot z,\, y_+$ are in cyclic order.
Then
$(y_+,y_-) \times [z,y \cdot z)$ is a Borel fundamental domain for the
$\langle y \rangle$-action on $\DG(S)$ (the set of pairs of crossing
geodesics, from Definition~\ref{def:intersection_currents}).

First we note that the following.

\begin{lemma}The intersection
of an oriented (or unoriented) closed curve $C$ with an oriented (or unoriented) geodesic current $\mu$ can be computed as
\[
i(\mu, C) = \mu((y_+,y_-) \times [z,y \cdot z)).
\]
\end{lemma}
\begin{proof}
  \DPTtodo[inline]{Maybe edit: $G[q,y\cdot q)$ and $(y_+,y_-)
    \times [z,y\cdot z)$ are just two different fundamental domains}
The claim follows from the fact that if $y \in \pi_1(\Sigma)$ denotes the element representing the oriented curve $C$, then for any $q \in \ora{y}$,
\[
\mu(G[q, y \cdot q))= \mu((y_+,y_-) \times [z,y \cdot z))
\]
for every $z \in \partial_{\infty} S - \{ y_-, y_+\}$ so that
$y_-, z, y \cdot z, y_+$ are in cyclic order.
This is
spelled out in detail in the proof
of~\cite[Lemma~4.4]{MZ19:PositivelyRatioed}, (cf.
\cite[Page~153]{Otal90:SpectreMarqueNegative}). The proof only uses
the $\pi_1(S)$-invariance of $\mu$, and no flip-invariance.
\end{proof}

We finish by proving Theorem~\ref{thm:intersect}, in the following
form.

\begin{theorem}
Let $f \colon \Curves(S) \to \mathbb{R}$ be a curve functional satisfying smoothing, additivity, stability and homogeneity.
For $C$ a closed curve, we have
\[
i(\mu_f,C)=i(\overline{\mu_f},C)=f(C).
\]
In particular, $\overline{\mu_f}$ is unique among unoriented geodesic currents.
\label{prop:recoverintersection}
\end{theorem}
\begin{proof}
We first prove that $i(\mu_f,C)=f(C)$. Given a representative $y \in \pi_1(S,*)$ of the conjugacy class~$C$, we will first show that we can use right handed boxes to approximate a fundamental domain for $\supp \mu \times \{ \ora{y} \}$ in $\DG(\Sigma)$.
Second, we'll show that computing the measure of that fundamental domain yields $f([y])$.


Choose a conjugate $y$ in $[y]$, 
and $p_1, q_1 \in \pi_1(S,*)$, so that $x$ crosses $p_1$ to the right, i.e., $p_1^{-1}$ crosses $x$ to the right, and $p_1$ crosses $y$ to the right.
Furthermore, choose $q_1$ so that $q_1$ crosses $x$ and $y$ to the right. 
Then, by Lemma~\ref{lem:rhs}, we have a configuration of lifts like the upper left and right lifts of $\ora{x}$ in Figure~\ref{fig:fundamental}.
Moreover, this choice guarantees that $q_1 p_1$ crosses $y$ to the right and thus, by Lemma~\ref{lem:rhs}, $\ora{y}$ is parallel to $q_1 p_1 \cdot \ora{y}$.

For each $n$, define the following elements of $\pi_1$:
\begin{align*}
  p_1^{(n)} &\coloneqq p_1 & q_1^{(n)}&\coloneqq y^n q_1\\
  p_2^{(n)} &\coloneqq p_1 y &q_2^{(n)} &\coloneqq y^{-(n+1)} q_1.
\end{align*}

We furthermore need to make further assumptions on $p_1,q_1,p_2,q_2$ in order to guarantee assumption~\ref{item:box-edges-cross-lift} in the definiton of RH lift system. Namely $p_1^{(n)} P_2^{(n)}=p_1 Y^n p_1^{-1}$ cannot be a power of $x$, for any $n$, and $Q_2^{(n)}q_1^{(n)} = Q_1 Y^{-2n-1}q_1$ cannot be a multiple of $x$ for any $n$. These conditions can be further guaranteed by slightly perturbing our previous choice of $p_1,q_1,p_2,q_2$, since all the conditions are open, and the set of lifts of closed geodesics is dense in the space of geodesics.
\begin{claim}
The datum $(p_1^n,p_2^n,q_1^n,q_2^n)$, as defined above, is a RH system, i.e.,
\begin{enumerate}
    \item $p_i^nq_j^n$ cross $x$ to the right, for $i,j=1,2$.
    \item $q_2^n x^m p_1^n$ crosses $q_1^n x^m p_2^n$ to the right, for $m \geq 0$. 
\end{enumerate}
\end{claim}
\begin{proof}
By NS dynamics of $y$, the translates of $\ora{x}$ by $(p_i^{(n)})^{-1}$ and $q_i^{(n)}$, for $i=1,2$, are like in Figure~\ref{fig:fundamental}.
\end{proof}

If we translate the RH lift system
$(p_1^{(n)},p_2^{(n)},q_1^{(n)},q_2^{(n)})$ into the orbit notation,
and set $p \coloneqq p_1$ and $q \coloneqq q_1$, we have right-handed boxes
\begin{align*}
  a^{(n)} &= p y^{n}   q &  b^{(n)} &= p y^{-(n+1)} q \\
  c^{(n)} &= p y^{n+1} q &  d^{(n)} &= p y^{-n} q.
\end{align*}

If we let $z=(p_1^{-1} \cdot \ora{x})^-$, and $B_n \coloneqq B_{a^{(n)}, b^{(n)}, c^{(n)}, d^{(n)}}$ then we have
    \begin{multline*}
      \mu_f((\gamma_-,\gamma_+) \times [z,y \cdot z)) \\
      \begin{aligned}
    &= \lim_{n\to\infty} \mu_f(B_n)  \\
    &= \frac{1}{2}\lim_{n\to\infty} \lim_{m\to\infty}f([py^{n+1}qx^{m}]) + f([py^{-(n+1)}qx^{m}])-f([py^{n}qx^{m}]) - f([py^{-n}qx^{m}]) \\
    &=\frac{1}{2}\lim_{n,m\to\infty}(f([py^{n+1}qx^{m}]) - f([y^{n+1}]) - f([x^m])) \\
    &\qquad+ (f([py^{-(n+1)}qx^{m}])-f([y^{-(n+1)}]) -f([x^m])) \\
    &\qquad-(f([py^{n}qx^{m}])-f([y^n])-f([x^m]))\\
    &\qquad- (f([py^{-n}qx^{m}])-f([y^{-n}])-f([x^m])) \\
    &\qquad+ f([y^{n+1}])+f([y^{-(n+1)}]) - f([y^n]) - f([y^{-n}])\\
    &= \frac{1}{2}(f([y]) + f([y^{-1}]))\\
    &=f([y]).
      \end{aligned}
    \end{multline*}      The first equality follows by the fact that the boxes defined
      above converge from below to $(\gamma_-,\gamma_+) \times [z,y
      \cdot z)$ as $n \to \infty$, since $B_{n-1} \subset B_n$. The second equality is by
      definition of the measure $\mu_f$ on boxes.
      For the third, we pass from double limit to each one of the iterated limits by Lemma~\ref{lem:additivity-limit-2} and we add and subtract the necessary powers of~$y$,
      $y^{-1}$ and $x$. The hypotheses of that Lemma are satisfied by the choice of $p_1$ and $q_1$.
      In the fourth equality, we then apply that
      Lemma to cancel out equivalent
      terms. In the fifth equality, we use the symmetry property of~$f$ to obtain the result.

      It remains then to check the property $i(\overline{\mu}_f, C)=f(C)$ for any closed curve $C$ persists. Indeed,
\[
i(\sigma_*(\mu_f),C)=i(\mu_f,\sigma_*(C))=i(\mu_f,C^{-1})=i(\mu_f,C).
\]
The first equality is by the fact that intersection number is invariant under the action of the flip map on both factors, and the fact that the flip map is an involution; the last equality is because of symmetry of intersection number.
Therefore, $\overline{\mu_f}$ is a geodesic current with the same intersection numbers as the oriented geodesic current $\mu_f$.

 Finally, the uniqueness of the geodesic current $\overline{\mu_f}$ is
 guaranteed by the fact that geodesic currents are uniquely determined
 by their intersection numbers with all closed curves by a result of
 Otal \cite[Th\'eor\`eme~2]{Otal90:SpectreMarqueNegative}.
\end{proof}

\begin{remark}
In \cite[Proposition~4.3]{BIPP24:PositiveCrossratios} the authors
construct a geodesic current induced from a cross-ratio.
Given a dense subset $X \subset \partial_{\infty} S$, they consider the set of $\mathcal{R}(X)$ of all proper rectangles of geodesics with endpoints on $X$.
They start from a finitely additive function $r \colon \mathcal{R}(X) \to \mathbb{R}$ (defined suitable from a cross-ratio)
satisfying that (1) if $R,R_1,R_2 \in \mathcal{R}(X)$ with $R=R_1 \cup R_2$, with $R_1,R_2$ disjoint, $r(R)=r(R_1)+r(R_2)$, 
and (2) so that if $R,R' \in \mathcal{R}(X)$ if $R \subset R'$, we have $r(R) \leq r(R')$.

Our function $\mu_f$ satisfies properties (1) and (2) by Proposition~\ref{prop:sidebyside}
and Proposition~\ref{prop:finitely-additive}, however, it is only defined in a proper subclass of $\mathcal{R}(X)$ (with $X$ the set of endpoints of translates of $x$, which is dense in $\partial_{\infty} S$  by Lemma~\ref{lem:minimal}).
Therefore, we cannot directly apply their result.

Moreover, we need the extra control on the family of right-handed boxes we consider in order to be able to recover the curve functional $f$ from the geodesic current we construct (see Theorem~\ref{prop:recoverintersection}).
In Section~\ref{sec:crossratios}, we prove that every cross-ratio induces a curve functional (i.e., period) satisfying the hypotheses of our Theorem~\ref{thm:intersect}, and thus our result generalizes \cite[Proposition~4.3]{BIPP24:PositiveCrossratios}.
\end{remark}

The end of the proof of Proposition~\ref{prop:recoverintersection} is the only place where we have used the symmetry condition of $f$. In fact, note that before that step, the proof shows the curve functional induced by the intersection number must be symmetric. 
The symmetry condition has also been used in Corollary~\ref{cor:cont_conn_disc}, and will be used in proving the equivalent algebraic statement Theorem~\ref{thm:intersections_group}.
This condition is thus crucial to recover curve functionals as intersection numbers. In Appendix~\ref{sec:asymmetric} we show that the asymmetric intersection numbers do not satisfy an analogous duality result.
\end{remark}

\subsection{Proof of Theorem~\texorpdfstring{\ref{thm:intersections_group}}{muf}}
\label{subsec:algebraic_vs_top}
We finish this section by proving its algebraic version, namely, Theorem~\ref{thm:intersections_group}.


\begin{proof}[Proof of Theorem~\ref{thm:intersections_group}]
Let $\overline{f}(a) \coloneqq \frac{1}{2}\left(f(a) + f(A) \right)$. Note that since $f$ is additive, $\overline{f}$ is also additive.
First, extend $\overline{f}$ linearly to $\mathbb{R}_{\geq 0}$-formal linear combinations of $\Gamma$, i.e., to weighted multi-curves, by the additivity of $\overline{f}$:
\[
\overline{f}(s \cdot a + t \cdot b) = s\cdot \overline{f}(a) + t \cdot \overline{f}(b)
\]
for every $s,t \geq 0$, and $a,b \in \Gamma$.

To prove the theorem, we will show that (this extension of) $\overline{f}$ satisfies the hypothesis of Theorem~\ref{thm:intersect}, and then apply that Theorem to conclude.

The only condition that requires verification is smoothing.

Start by assuming the essential crossing arises from an essential crossing between two curves $C_1$ and $C_2$ represented by elements $a,b$ (by Proposition~\ref{prop:crossings-triality}), and we will conclude disconnected smoothing.
In this case, either $(\ora{a},\ora{b})$ are $R$-crossing, or $(\ora{a},\ora{b})$ are $L$-crossing. If $(\ora{a},\ora{b})$ is $R$-crossing, then oriented disconnected smoothing is satisfied by the hypothesis.  If $(\ora{a},\ora{b})$ is $L$-crossing, $(\ora{b},\ora{a})$ is $R$-crossing and, similarly, the hypothesis tells us
\[
\overline{f}(a) + \overline{f}(b) = \overline{f}(b) + \overline{f}(a) \geq \overline{f}(ba)= \overline{f}(ab)
\]
where just used in the last equality that $\overline{f}$ is conjugacy invariant.
Now, we assume an essential self-crossing of a multi-curve, and prove connected smoothing.

Using Proposition~\ref{prop:crossings-triality}, assume the essential self-crossing is realized by the self-intersection of a curve $[\gamma]=[ab]$, where $\ora{a},\ora{b}$ are parallel (the anti-parallel case is similar).
If $\ora{a},\ora{b}$ are $R$-parallel, by assumption, we have that oriented connected smoothing is satisfied.
If $\ora{b},\ora{a}$ are $L$-parallel, then $\ora{a},\ora{b}$ are $R$-parallel. Hence
\[
\overline{f}(ab)=\overline{f}(ba) \geq \overline{f}(b) + \overline{f}(a) = \overline{f}(a) + \overline{f}(b).
\]
If $(a,b)$ are $L$-parallel, then $(b,a)$ are $R$-parallel, thus
\[
\overline{f}(ab)=\overline{f}(ba)\geq \overline{f}(b) + \overline{f}(a) = \overline{f}(a) + \overline{f}(b). 
\]
Hence, oriented connected smoothing is satisfied in this case, too.
Finally, by Corollary~\ref{cor:oriented_smoothing_unoriented} $\overline{f}$ satisfies smoothing. We are thus under the hypotheses of Theorem~\ref{thm:intersect}.
\end{proof}
